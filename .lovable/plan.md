# PORTALIS corporate website

## Goal
Build a premium marketing website for Portalis that explains its vehicle-entry technology, demonstrates credibility, and drives demo enquiries without implying live deployments, customer results, or functional ANPR software.

## Pages
- **Home** — sticky navigation, grounded gate-entry hero, audience strip, problem framing, five-step workflow, illustrative product interface, capabilities, “Why Portalis,” and a strong contact prompt.
- **Solutions** — detailed capability sections for vehicle identification, digital entry/exit records, vehicle management, and security-team support.
- **How It Works** — a clear property-entry workflow with deployment and existing-infrastructure context.
- **Why Portalis** — positioning around visibility, operational clarity, responsible automation, and practical property fit.
- **Contact** — focused demo-enquiry form with clear expectations and no invented office details.

## Visual direction
- Precision-led editorial layout using near-black, off-white, white, and restrained electric blue.
- Strong open-source sans-serif typography, architectural grids, fine borders, compact labels, and minimal radii.
- Generate a realistic modern residential entrance image with a vehicle approaching a controlled gate; layer a restrained, explicitly simulated identification interface over it.
- Use controlled motion only: navigation compression, scanning line, subtle vehicle/indicator movement, and purposeful reveal transitions with reduced-motion support.
- Responsive desktop and mobile navigation, process timeline, product visualization, tables, and contact layouts.

## Content and safeguards
- Use the supplied headlines, positioning, problem points, workflow, example interface values, and service descriptions.
- Label all interface imagery and values as illustrative.
- Do not add testimonials, customer logos, statistics, awards, certifications, partners, guarantees, or unsupported claims.
- Do not add login, dashboards, databases, payments, camera streaming, backend processing, or fake live data.

## Technical details
- Preserve TanStack Start routing and create a dedicated route for each navigation destination.
- Define the complete semantic token system and animation primitives in the global stylesheet.
- Create reusable site navigation, footer, call-to-action, and visual modules.
- Add unique metadata for every page and verify layout and navigation on desktop and mobile.
